# Website-Rental-Kamera
Rental Kamera
Rental Kamera adalah sebuah platform penyewaan kamera yang memungkinkan pengguna untuk menyewa berbagai jenis kamera dan peralatan fotografi dengan mudah. Website ini menyediakan berbagai fitur untuk memudahkan pengguna dalam melakukan pemesanan, pendaftaran akun, dan menghubungi penyedia layanan.

Fitur Utama
1. Pendaftaran dan Login Pengguna:
Pengguna dapat mendaftar akun baru dengan memasukkan nama, email, dan password.
Pengguna yang sudah terdaftar dapat login menggunakan email dan password mereka.

2. Penyewaan Kamera:
Pengguna dapat melihat daftar kamera yang tersedia untuk disewa.
Setiap kamera dilengkapi dengan deskripsi spesifikasi dan harga sewa per hari.
Pengguna dapat memilih kamera yang ingin disewa, menentukan jumlah hari sewa, dan mengirimkan pesanan.

3. Manajemen Pesanan:
Pengguna dapat melihat daftar pesanan mereka, termasuk detail seperti nama kamera, tanggal mulai, tanggal selesai, dan total harga.
Pengguna dapat memperbarui status pesanan (misalnya, konfirmasi, selesai, atau batalkan).

4. Formulir Kontak:
Pengguna dapat mengirim pesan kepada penyedia layanan melalui formulir kontak.
Pesan yang dikirim akan disimpan dalam database untuk ditindaklanjuti oleh penyedia layanan.

Teknologi yang Digunakan

1. Frontend:
HTML, CSS, dan JavaScript untuk tampilan dan interaksi pengguna.
Formulir pendaftaran, login, dan penyewaan kamera yang responsif dan mudah digunakan.

2. Backend:
PHP untuk memproses permintaan dari frontend dan berinteraksi dengan database.
MySQL sebagai database untuk menyimpan data pengguna, pesanan, dan pesan.
